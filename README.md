# Izkeser — «Сөз тапқанға қолқа жоқ»

Образовательная игра с роботом DerekSci (MVP, фронтенд на vanilla JS + мок-бэкенд). Первое приключение — «Детектив текста».

Игра по ТЗ `TZ_Obrazovatelnaya_igra_DerekSci_MVP_Laravel.md`. Контент (сюжет, 47 карточек пяти режимов, финал)
взят из сценария «читалка (1).docx».

## Запуск

Сборка не нужна. Подойдёт любой статический сервер:

```bash
python -m http.server 5173
# открыть http://localhost:5173
```

Данные мок-бэкенда хранятся в `localStorage` браузера (ключ `dereksci_mock_db_v2`).

## Встраивание в платформу (левое меню 232px)

Своего бокового меню у приложения нет. Предполагается, что у платформы-хоста слева есть меню шириной 232px.

- Всё приложение находится внутри `#ds-app` и занимает контентную область хоста.
- Фиксированные элементы смещаются на `--ds-host-sidebar`: нижняя панель урока, модальные окна и тосты.
  Переменная равна `232px` при ширине ≥1024px и `0` на узких экранах (в `css/styles.css`, блок `:root`).
  Если у хоста другая ширина меню или другая точка перелома, поменяйте значение там.
- `body.standalone` в `index.html` нужен только для автономного запуска: он резервирует 232px слева
  и показывает пунктирную заглушку. При встраивании этот класс и `.host-stub` надо убрать.

## Иконки и сюжетные анимации

- Иконки берутся из Lucide: `DS.ui.icon('book-open', 20)`. Принимается любое имя Lucide в kebab-case.
  Иконки городов, направлений и достижений в контенте тоже заданы именами Lucide.
- Над каждой репликой вступления мира показывается анимированная сцена (поле `scene` в `worlds[].intro`, файл `js/mock/data.js`):
  мир 1 — `alert`, `mismatch`, `chaos`, `eye`, `partner`, `route`; мир 2 — `observatory`, `signals`, `stations`.
  Вступления городов используют поле `scene` у города (`archive`, `fog`, `stamps`, `sorting`, `navigator`,
  `radio`, `greenhouse`, `lab`, `planets`, `compasses`) — сцена показывается над каждой репликой города.
  Финалы: мир 1 — `reveal`, `keeper`, `screwdriver`, `celebrate`, `routeplan`; мир 2 — `constellation`, `celebrate2`, `share`. Чтобы поставить готовую GIF или видео-иллюстрацию,
  задайте реплике `media: { src: 'assets/intro-1.gif', alt: 'описание' }` — оно показывается вместо сцены.
  При настройке «Меньше анимации» сцены показываются статичным кадром.

## Бесконечная игра

- **Вселенная — цепочка миров.** Мир 1 «Детектив текста» (сценарий) → мир 2 «Звёздный архив» (демо-контент) → миры из CMS.
  Финал каждого мира («ПОЛУЧЕНО НОВОЕ ДЕЛО») ведёт в следующий мир. Мир N+1 открывается после последнего урока мира N.
- **Миры из CMS** (`CMS → Миры`): редактор создаёт мир, города и уроки, добавляет задания; администратор публикует мир.
  Пустой мир (без городов, уроков или опубликованных заданий) не публикуется. Опубликованный мир встаёт в конец цепочки.
- **Бесконечные экспедиции** открываются после первого мира. Каждая экспедиция — процедурный город
  («Экспедиция №7: Гавань Северных Архивов») из 5 проверенных заданий пройденных уроков. Чаще попадаются задания
  с открытыми ошибками и задания слабых навыков, недавние повторяются реже. Награда: +10 XP за задание, +15 XP и +3 монеты
  за экспедицию; достижения за 1, 5, 10, 25, 50, 100 экспедиций.

## Демо-режим

На приветственном экране и в профиле (блок «Демо-режим мок-бэкенда») есть два пресета:
- **«Всё пройдено»** — пройдены оба мира, открыты финалы и экспедиции;
- **«Перед финалом»** — пройдено всё, кроме последнего урока первого мира: можно сыграть его и увидеть финал
  и переход к новому делу.

С приветственного экрана создаётся отдельный демо-игрок (пароль `demo1234`). Пресеты работают только в мок-бэкенде.

## Как мок соответствует ТЗ

- `answer_key` не попадает в ответы API. Проверка ответа выполняется в `server.js`.
- Первая ошибка: отклик и подсказка, правильный ответ не раскрывается. Вторая ошибка: объяснение и правильный вариант.
- Порог прохождения урока — 60% правильных ответов с первой попытки. Точность считается только по первым попыткам.
- Награды: +10 XP за задание (один раз за сессию), +20 XP и +5 монет за первое прохождение урока.
  Награды пишутся в `wallet_ledger` с уникальным ключом `(user, event_type, source_id)`, поэтому повторное или
  параллельное завершение урока ничего не начисляет второй раз.
- `client_attempt_id` обеспечивает идемпотентность: повторная отправка ответа возвращает прежний результат.
- Закрытые уроки возвращают 403 даже при переходе по прямой ссылке. Чужая сессия возвращает 404.
- Незаконченный урок можно продолжить (`Продолжить` на главной), прогресс переживает перезагрузку страницы.
- Ошибки попадают в «Повторение». Навыки оцениваются по последним 10 первым попыткам: меньше 5 ответов —
  «недостаточно данных», точность ниже 70% — рекомендация повторить.
- После каждого города открывается фрагмент сообщения. После пятого показывается финал с Хранителем и значок «Детектив текста».
- CMS: черновик → проверка → публикация. Опубликованная версия неизменяема, правка создаёт новую версию,
  а сессии ссылаются на `question_id@vN`. Есть журнал изменений и аналитика событий.
- Профиль «учитель» не даёт доступа к CMS. Серверные роли в демо выдаются в профиле
  («Демо-режим мок-бэкенда»), в Laravel их выдаёт администратор.

## Переход на Laravel

В `js/api.js` установить `USE_MOCK: false` и `BASE_URL`. Маршруты и форматы ответов повторяют `server.js`.
Клиент ожидает ошибки в формате `{ message, code, errors }`.
